# 信頼ジャンケン ONLINE v4

## 起動
1. このフォルダで `npm install`
2. `npm start`
3. PC: http://localhost:3000
4. 同一Wi-Fi端末: http://PCのIPv4アドレス:3000

## v4 変更点
- 通常ラウンドで、全員が同じ手なら ✊ / ✋ / ✌️ のどれでも「全員セーフ」
- リーチ判定中も従来通り、残りの参加者が全員同じ手なら元リーチ者を引き戻し
- ホストが参加者ごとのカラーをカラーピッカーで変更可能
- 参加者カラーを参加者カードと公開演出に反映
- 「構えて！」の効果音を添付の `drum-japanese2.mp3` に変更

## v5 表示改善
- 参加者カード内の状態を大きなバッジで表示
- 敗北：赤文字＋赤枠
- リーチ：黄色文字＋強調枠
- 勝利：黄色文字＋強調枠
- ゲーム中：通常色
- 選択済み / 未選択 / 待機中は状態の下に分離表示

## v6
- 「公開」ボタンで全員の手が大きく表示される瞬間に、添付の「ロールの閉め.mp3」を再生
- 構えて！の drum 効果音はそのまま維持

## v7 修正
- v6で「部屋を作る」「参加する」等の操作関数が抜けていた不具合を修正
- ホスト操作、色変更、手の選択、公開、構えて、リセットをすべて復元
- v6までの効果音・色・状態表示はそのまま維持

## v8 再接続対応
- スマホのスリープや一時的な回線落ちで切断されても、参加枠を削除しない
- 回線復帰時に同じ端末なら自動で元の参加枠へ復帰
- ページを再読み込み・ブラウザを開き直しても、保存された部屋コードと名前で自動復帰
- 別端末からでも、切断中の参加者と同じ「部屋コード＋名前」で参加すると元の状態へ復帰
- リーチ / 勝利 / 敗北 / 選択済みの手を保持
- ホストも一時切断で部屋が即終了せず、自動復帰可能
- 切断中の参加者は「📶 回線切断中」と表示
- 全員が30分以上切断された部屋のみ自動削除

## v9

- 勝者は黄色、脱落者は赤で表示
- 各参加者の設定カラーも小さな色マーカーとして表示
- 画面幅が狭い場合は自動で縦並び

## v19

- ✊+✌️では誰も脱落しない
- リーチ中に✊+✌️など決着条件がなければリーチ維持で再選択
